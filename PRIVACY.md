# Privacy Policy

Data Workbench 2.0 is **local-first by default**:
- Uploaded files and pasted datasets are processed strictly in your local browser memory or local CLI process.
- No cell values, filenames, API keys, or raw datasets are transmitted to external servers.
- The built-in AI Rule Copilot operates deterministically on your local device with zero outbound network calls.
- Exported Workflow Packages exclude raw customer data by default.
- MCP Server previews automatically mask detected PII columns.
